# Предпочтения пользователя

- Всегда сохраняйте завершённые изменения кода в подключённом GitHub:
  делайте коммит и push в текущую рабочую ветку после уместной проверки.
  Не включайте секреты, приватные ключи, сессии, личные списки кошельков
  и большие архивы. Если отправка не удалась, сообщайте об этом явно;
  локальный коммит не означает сохранение на GitHub.
- В каждом HTML-графике и аналогичном интерактивном отчёте сохраняйте кнопку
  «Сохранить график» (или «Сохранить отчёт») внутри самой страницы.
- Используйте скачивание автономного HTML через Blob и ссылку с атрибутом download,
  как в chart_template.html. Этот способ проверен пользователем и работает.
  Скачивание артефактов через панель Codex у пользователя выдаёт ошибку;
  не полагайтесь на него как на единственный способ сохранения.
- Объясняйте работу простыми словами и давайте пошаговые инструкции:
  пользователь впервые работает с Codex и AI-агентами.
- Для купленного архива 0xArchive пользователь выбрал обработку в облаке:
  установка и запуск Python на его Windows оказались слишком сложными.
  Подписанные ссылки на скачивание передавайте через настройки среды,
  не включайте их значения в код, отчёты, журналы или чат.
- Новый бот должен получать списки Wallet Tracker и покупки/продажи только из
  GMGN. Пользователь явно отклонил получение этих событий через блокчейн или
  замену GMGN другим источником. Не придумывайте эндпоинты и не заявляйте, что
  торговый API-ключ даёт доступ к сохранённому Wallet Tracker без проверки.
  Требуются уведомления в Telegram по приоритетным сохранённым кошелькам.
- Выбор кошельков меняет только отдельный фильтр Telegram-бота. Все подписки
  и настройки отслеживания в GMGN должны оставаться без изменений. Не вызывать
  добавление/удаление подписок, изменение списков, торговлю или другие операции
  записи в GMGN; для интеграции нужны только запросы чтения.
- Пользователь отказался устанавливать наше расширение Chrome. Не продолжайте
  этот способ без нового явного согласия. Созданный browser_extension/ — только
  проверочный пакет, не работающий мониторинг.
- Пользователь явно разрешил переписку агента с официальной поддержкой GMGN
  для устранения проблем API. Проверенный канал: https://t.me/gmgnagentapi.
  Не передавайте поддержке API-ключи, токены, приватный ключ, личный список
  кошельков или баланс. Допустимы HTTP-статусы и Ray ID. Не называйте обращение
  отправленным без квитанции. Наш бот должен иметь законное членство и право
  писать в группе; не имитируйте личный Telegram-аккаунт без штатного
  авторизованного входа.
- Пользователь создал новый отдельный Telegram-аккаунт и папку «Codex» для
  согласованных переписок агента. Аккаунт ещё НЕ подключён к среде: не заявляйте
  о переносе чатов или отправке сообщений до реального входа и проверки.
  Из этого аккаунта перед каждым исходящим сообщением показывайте адресата
  и точный текст, ждите разрешения пользователя; общее разрешение на поддержку
  GMGN не отменяет это более позднее условие. Пользователь разрешил помещать
  согласованные переписки в папку «Codex». Пароли, коды и файлы сессии в чат
  не запрашивать. Предпочтителен официальный QR-вход с подтверждением владельцем.
